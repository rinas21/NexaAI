# ADR-005: MCP Server for Tool Exposure

- **Status**: Accepted
- **Date**: 2026-11-25

## Context
Need to demonstrate an emerging standard for AI tool interoperability and allow external clients to discover/call approved business tools.

## Decision
Implement an MCP server in Python exposing document search, document listing, calculator, and datetime. Provide a small MCP client demo. All calls require caller identity and permission checks.

## Consequences
- Demonstrates MCP integration without adding a separate deployment unit (lives in the AI service).
- Tool definitions are decoupled from the agent runtime.
- Uses the `mcp` package when available with a simple JSON-RPC-style fallback for local testing.
